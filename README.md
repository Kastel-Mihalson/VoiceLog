# Голосовой дневник (Android)

Приложение записывает голосовые команды в разделы: траты, отжимания, таблетки и любые другие, которые вы создадите сами.

Пример: нажимаете на кнопку микрофона и говорите
«Добавь в раздел траты покупка чая стоимостью 254 рубля 55 копеек» — приложение добавит запись
«Покупка чая — 254,55 ₽» в раздел «Траты» с текущей датой и временем.

## Как запустить на телефоне

1. Установите [Android Studio](https://developer.android.com/studio) (бесплатно).
2. `File → Open` и выберите папку `VoiceLog` (ту, где лежит `settings.gradle.kts`).
3. Дождитесь, пока Android Studio сама скачает Gradle и библиотеки (первый раз 3–10 минут,
   нужен интернет). Если IDE предложит обновить версии плагинов — можно согласиться.
4. На телефоне включите режим разработчика: `Настройки → О телефоне →` 7 раз нажать на «Номер сборки».
   Затем `Настройки → Для разработчиков →` «Отладка по USB».
5. Подключите телефон кабелем, разрешите отладку, в Android Studio выберите телефон
   в верхней панели и нажмите зелёную кнопку ▶ (Run).

### Если нужен APK-файл
`Build → Build Bundle(s) / APK(s) → Build APK(s)`. Готовый файл появится в
`app/build/outputs/apk/debug/app-debug.apk` — его можно скопировать на телефон и установить
(понадобится разрешить установку из неизвестных источников).

## Требования
- Android 8.0 (API 26) и новее.
- Для распознавания речи нужен «Голосовой ввод Google» (есть на большинстве телефонов).
  Русский язык можно скачать для работы офлайн: `Настройки → Язык и ввод → Голосовой ввод Google → Офлайн-распознавание`.
- Эмулятор: микрофон работает не всегда. Для проверки без микрофона на главном экране есть
  поле «Или введите команду текстом» — оно работает так же, как голос.

## Что есть в приложении
- **Главная** — кнопка записи чуть ниже центра, подсказки, ответы приложения, уточняющие вопросы.
- **Меню (бургер слева сверху)** — Главная, Записи, Настройки, переключатель тёмной темы.
- **Записи** — список ваших разделов (создать, изменить, удалить). Внутри раздела:
  дата → записи за этот день (время, описание, сумма/количество) → итог за день;
  итоги за сегодня/неделю/месяц; фильтр День / Неделя / Месяц / Всё со стрелками
  «назад-вперёд»; ручное добавление и удаление записей.
- **Настройки** — тема (светлая по умолчанию / тёмная / как в системе), озвучивание ответов,
  автопрослушивание ответа на вопрос, описание того, как распознаются команды,
  список разделов с их словами-подсказками.

## Как приложение понимает фразы
Всё работает на телефоне, на правилах (`voice/VoiceParser.kt`):
1. Числа словами → цифры («двести пятьдесят четыре» → 254).
2. Сумма: «254 рубля 55 копеек», «254,55», «254 ₽», «за 300»; количество: «30 раз».
3. Раздел: по названию или словам-подсказкам, с учётом окончаний. У каждого раздела
   можно задать свои слова (например, для «Траты»: потратил, купил, расход).
4. Остальное — описание. Дата и время ставятся автоматически.
5. Если не понятен раздел или число — приложение задаёт вопрос и снова включает микрофон.
   Скажите «отмена», чтобы прервать.

Примеры, которые разбираются:
- «Добавь в раздел траты кофе двести пятьдесят четыре рубля пятьдесят пять копеек»
- «Потратил 300 на такси» (раздел определится по слову «потратил»)
- «Отжимания 30 раз»
- «Выпил таблетку» (для разделов с выключенным «Уточнять число» запись считается за 1)
- «Добавь молоко 50 рублей» → приложение спросит, в какой раздел добавить

## Структура проекта
```
app/src/main/java/com/voicelog/app/
  MainActivity.kt          — вход в приложение
  MainViewModel.kt         — голосовой ввод, озвучивание, диалог уточнений, работа с базой
  voice/VoiceParser.kt     — разбор фразы (разделы, суммы, описание)
  voice/RussianNumbers.kt  — «двести пятьдесят» → 250
  data/                    — база данных Room (разделы и записи), настройки
  util/Fmt.kt              — форматирование сумм и дат
  ui/                      — экраны: Home, Records, Section, Settings, меню, тема
```
