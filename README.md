# Голосовой дневник (Android)

Приложение записывает голосовые команды в разделы. По умолчанию есть один раздел — «Траты»,
остальные вы создаёте сами (кнопкой или голосом).

Пример: говорите
«Добавь в раздел траты покупка чая стоимостью 254 рубля 55 копеек» — приложение добавит запись
«Покупка чая — 254,55 ₽» в раздел «Траты» с текущей датой и временем.

## Как получить APK
Сборка идёт в GitHub Actions (файл `.github/workflows/build-apk.yml`): при слиянии в `main`
или вручную (вкладка Actions → Build APK → Run workflow). Готовый `app-debug.apk` скачивается
в разделе Artifacts запуска.

Либо в Android Studio: `Build → Build APK(s)`.

## Обновление поверх установленной версии
Все сборки подписываются одним и тем же ключом (`app/voicelog.keystore`), а `versionCode`
растёт с номером сборки. Поэтому новый APK ставится **поверх старого**, без удаления,
и все записи сохраняются.

Важно:
- Первую сборку с этим ключом нужно установить один раз с удалением прежней версии
  (раньше ключ был случайным у каждой сборки). Дальше — только обновления.
- Если менять структуру базы данных (`data/`), нужна миграция Room, иначе данные пропадут.
- Ключ лежит в репозитории только для личного использования. Для публикации в Google Play
  сделайте отдельный секретный ключ.

## Интерфейс
- **Нижнее меню** (5 пунктов): Заметки, Статистика, **Голос** (в центре, открывается первым),
  Задачи, Настройки. Между пунктами можно переходить свайпом влево/вправо.
- **Голос** — кнопка записи (сама не включается), справа слайдер типа записи, поле ввода текстом.
- **Заметки** — список разделов-заметок и карточка «Все заметки». Раздел открывается и показывает
  заметки по дням (поиск, правка, удаление). Кнопка «Новый раздел» создаёт раздел заметок.
- **Статистика** — разделы с числами (траты и т. п.): итоги за день/неделю/месяц; внутри раздела —
  записи по дням, фильтры, ручное добавление, правка по нажатию. Кнопка «Новый раздел» — для статистики.
  У каждого раздела меню ⋮ (изменить / удалить).
- **Задачи** — список дел с галочками. Подвкладка «История»: выполненные задачи по дням,
  день раскрывается и показывает список.
- **Настройки** — тема, движок распознавания (Vosk / Google), озвучивание, справка по командам.

## Как записывается фраза
Тип записи выбирается слайдером справа от кнопки записи на странице «Голос» (Задача / Заметка / Статистика):
- **Задача** — фраза целиком попадает в список задач, ничего не распознаётся;
- **Заметка** — текст дословно в раздел заметок (по названию/словам; при конфликте приложение уточняет);
- **Статистика** — раздел по словам, сумма или число из фразы (недостающее приложение уточняет).

## Распознавание речи
В «Настройки → Распознавание речи»:
- **Vosk** — офлайн-модель на телефоне. Один раз нужно скачать русскую модель (≈45 МБ).
  После скачивания Vosk включается сам.
- **Google** — встроенный сервис телефона (по умолчанию, пока модель не скачана).

## Команды
- Запись: «Добавь в раздел траты кофе двести пятьдесят четыре рубля пятьдесят пять копеек»,
  «Потратил 300 на такси» (раздел определится по слову «потратил»).
- Новый раздел: «Создай раздел Игры» — приложение создаст раздел и спросит единицу измерения.
  Одной фразой: «Создай раздел Игры единица минуты слова играл партия».
  Единицы: рубли, раз, штуки, минуты, часы, дни, километры, граммы, литры, страницы и др.
  или «без единицы».
- «Отмена» — прервать уточняющий диалог.

## Если у разделов совпадают слова-подсказки
- Если слова совпали и фраза одинаково подходит двум разделам, приложение **не угадывает**,
  а спрашивает: «Фраза подходит к нескольким разделам: «Траты» или «Продукты». В какой добавить?».
- Название раздела в фразе («продукты купил хлеб») важнее слова-подсказки,
  а явное «в раздел продукты» важнее всего — тогда вопроса не будет.
- При создании раздела (кнопкой или голосом) приложение предупреждает о совпадающих словах.

## Структура проекта
```
app/voicelog.keystore       — общий ключ подписи (для обновления поверх старой версии)
app/src/main/java/com/voicelog/app/
  MainActivity.kt           — вход в приложение
  MainViewModel.kt          — голосовой ввод, озвучивание, диалог уточнений, работа с базой
  voice/VoiceParser.kt      — разбор фразы (разделы, суммы, описание, конфликты)
  voice/SectionCommand.kt   — команда «Создай раздел», единицы, пересечение слов
  voice/RussianNumbers.kt   — «двести пятьдесят» → 250
  voice/VoskModelManager.kt — скачивание модели Vosk
  data/                     — база данных Room (разделы и записи), настройки
  util/Fmt.kt               — форматирование сумм и дат
  ui/                       — экраны и нижнее меню
```
